# Configure an existing task

Use your scheduling tool to inspect an existing daily-brief task before changing
it. Preserve the selected schedule and avoid a duplicate. Point its prompt at
the production packet and your private run configuration. Explicitly record
draft-only or destination-specific publication authority.

Do not copy another creator's accounts, research inbox, local paths or recovery
authorization. The host must have the required tools and access when the task
runs. Scheduler registration and publishing readiness are separate checks.
